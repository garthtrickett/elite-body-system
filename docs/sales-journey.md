# EBS sales journey

The uploaded website is the design and copy authority. Its source files are
preserved in the sales feature, with the requested price-free investment question.
The two access options are discussed on the call: £2,400 group/community and
£5,000 individual access. Do not add a public tier comparison or promise individual
access in newly written funnel copy.

## Team workflow

1. Open EBS Master, then Elite Sales System.
2. Select a lead. Read their application and journey.
3. Open the call guide from that lead to retain their goals and obstacles beside
   the CLOSER questions.
4. Listen and clarify before presenting the system or support options.
5. Add a factual note and agree a next step. Change the stage only when warranted.
6. Mark Client after enrolment is confirmed; this does not process payment or
   automatically provision a member account.

Bookings use explicit availability with no overlapping slots. Confirmation reserves
one slot, updates the lead and opens Client Stories. Add to calendar produces an
ICS file for that browser's confirmed booking. Cancel booking releases the slot,
preserves the journey event and returns a Call booked lead to Applied. Cancellation
updates the app; contact the client separately. No external booking or cancellation
message is sent by this build.

Free Value records an explicit insights signup and consent. The email series is not
enabled. Signup immediately opens the 30-day web guide, with one idea and action
per day. Edit all thirty entries under Funnel pages → Free value. Leaving the list
withdraws the signup while retaining the enquiry/application record.

Client-story drafts remain private. Publish only owner-approved names, media and
results. The public feed loads more on scroll, with a button fallback. Real videos
are still to be supplied.
